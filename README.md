# Домашнє завдання 4: рекурсія та алгоритми сортування

## Завдання 1. Рекурсивне сортування файлів

```bash
python task1.py шлях/до/джерела [шлях/до/призначення]
```

Якщо директорію призначення не вказано, використовується `dist` у поточній директорії. Файли рекурсивно копіюються в піддиректорії за розширенням; файли без розширення потрапляють у `no_extension`. Оригінали не видаляються. Символічні посилання пропускаються, а файли з однаковими назвами отримують числовий суфікс, щоб уникнути перезапису. Помилки читання та копіювання виводяться в stderr; за наявності помилок програма завершується з ненульовим кодом.

## Завдання 2. Сніжинка Коха

```bash
python task2.py --level 4
```

Якщо `--level` не задано, програма запитає його в терміналі. Підтримується рівень від 0 до 8; для відображення використовується стандартний модуль `turtle`.

## Завдання 3. Порівняння сортувань

```bash
python task3.py
python task3.py --sizes 100 1000 5000 --repeats 3
```

Скрипт порівнює сортування вставками, сортування злиттям і `sorted` (Timsort) на випадкових, відсортованих, обернено відсортованих і майже відсортованих наборах. Усі алгоритми отримують копію одного й того самого набору, вимірювання виконує `timeit` (`number=1`), а в таблицю виводиться найкращий час із повторів. Копіювання включене в замір для всіх трьох алгоритмів.

### Аналіз і висновки

Сортування вставками має квадратичну складність у середньому та найгіршому випадках, $O(n^2)$, але працює за $O(n)$ на вже відсортованих даних. Сортування злиттям має $O(n \log n)$ у найкращому, середньому й найгіршому випадках, ціною додаткової пам'яті. Timsort має найгіршу складність $O(n \log n)$ і може працювати за $O(n)$ на впорядкованих серіях.

На випадкових 3000 елементах сортування злиттям було приблизно у 26 разів швидшим за вставки, а Timsort — приблизно у 16 разів швидшим за злиття. На вже відсортованих даних вставки працювали швидко завдяки лінійному найкращому випадку; майже відсортовані дані також показують користь від упорядкованості. Timsort стабільно показав найменший час у цих вимірах. Сортування злиттям масштабується краще за вставки на випадкових даних, але написана на Python реалізація має накладні витрати рекурсивних викликів та створення проміжних списків. Timsort поєднує обробку природних упорядкованих серій та ефективне злиття, а критичний код виконується в C; тому вбудоване сортування зазвичай найшвидше й добре використовує вже впорядкованість даних. Часи залежать від обладнання та версії Python. Для прикладного коду варто віддавати перевагу `sorted` або `list.sort()`, а власні алгоритми реалізовувати для навчання чи спеціальних вимог.
